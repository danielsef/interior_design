# 10-wc — WC
| | |
| --- | --- |
| **Terület** | 1,63 m² |
| **Burkolat** | Kerámia |
| **Képek a mappában** | 5 db |

## Mit keress

- Matt fehér csempe, nagyformátumú lap (tágít)
- Kis fa mosdószekrény vagy fa polc – meleget visz a fehérbe
- Padlóig futó vagy nagy tükör
- Fehér lambéria – itt működik a legjobban

> **Cream beige nyílászárók és fa párkányok.** A meglévő szín és a szálcsiszolt sárgaréz kilincsek a referenciák; az új bútor- és textilszíneket a fehér fallal, padlóval és megrendelt bútorokkal közös mintasorban ellenőrizzük. A képek formai inspirációk, nem új beszerzési előírások.

## Mit kerülj

- Sötét csempe
- Apró mozaik sötét fugával
- Zsúfolt polcok
